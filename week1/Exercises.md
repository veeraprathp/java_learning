# Week 1 Exercises

Write each solution in its own file inside `week1/`. Try before asking for hints.

1. **Hello You** (`Ex1_Hello.java`): Store your name and city in variables and print `Hi, I'm <name> from <city>`.
2. **Even or Odd** (`Ex2_EvenOdd.java`): For a number stored in a variable, print whether it is even or odd.
3. **Multiplication table** (`Ex3_Table.java`): Print the table of 7 from 1 to 10 using a `for` loop.
4. **Sum of 1..100** (`Ex4_Sum.java`): Compute the sum using a `while` loop.
5. **FizzBuzz** (`Ex5_FizzBuzz.java`): For 1..30 print `Fizz` for multiples of 3, `Buzz` for multiples of 5, `FizzBuzz` for both, otherwise the number.

## Mini project
**Number guessing game** (`GuessGame.java`): the program picks a number 1-100 (`new java.util.Random().nextInt(100) + 1`), reads guesses with `java.util.Scanner`, and says "higher" or "lower" until you win. Print the number of attempts.
